## 3. 대체가 성립하는 근거

- ADR. 회의록의 실질 산출은 합의문이 아니라 "무엇을 왜 택했고 무엇을 왜 버렸는가"다. ADR 13편이 결정·근거·대안·영향을 고정 형식으로 담고, 기각 대안 68건에 각각 기각 사유가 붙어 있다. 예: ADR 0002는 Redisson 리더선출을 기각하면서 배선 부재를 `grep -rniI "redisson" server/` 2건(둘 다 주석)과 gradle 의존 0건으로 증명한다.
- 역할 하네스. 분담표의 목적은 이름 배정이 아니라 경계 확정이다. 정의 파일이 담당 범위, 정본 계약, 불변 규칙, 도구 권한을 문장으로 못박아 경계가 실행 시점에 강제된다.
- reviewer 판정. 승인 이력의 목적은 서명이 아니라 결함 검출이다. reviewer는 Edit·Write가 없어 "고쳐 두겠다"로 넘어가는 경로가 구조적으로 없고, 지적은 반드시 구현 역할의 다음 커밋으로만 해소된다. 그래서 판정과 교정이 다른 커밋으로 분리돼 이력에 남는다.
- 커밋 귀속. 담당자 열의 목적은 추적성이다. 사람 이름 대신 역할과 커밋 해시로 귀속했고, 기준 커밋 `581d5f3`까지 314개 커밋이 빠짐없이 WBS 행에 매핑된다. 누락 0, 미해석 해시 0.
- 자동 게이트. 교차 검토의 목적은 개인 실수의 검출이다. 사람 둘을 기계 셋으로 바꿨다. 판정의 하한이 사람 판단이 아니라 exit code에 있으므로 판정자의 컨디션이나 관대함이 결과를 바꾸지 못한다.
- 마일스톤 실적. 진척 보고의 목적은 계획과 실적의 차이를 드러내는 것이다. 계획 분기와 실수행 40일의 괴리를 지우지 않고 비고에 그대로 적었고, 미달 항목(soak 2시간, 설정 화면, E3)을 마일스톤별로 명시했다.

## 4. 대체가 성립하지 않는 부분

이 절이 없으면 앞의 표는 자기 홍보다.

- 합의 형성. ADR은 결정 기록이지 합의 과정이 아니다. 서로 다른 경력과 이해관계에서 나오는 반대 의견, 그것을 조율하는 협상은 이 체계에 없다. 정본 문서는 이미 내가 쓴 것이므로 내가 처음부터 틀리게 쓴 전제는 판정 단계에서 걸러지지 않는다.
- 타인의 시선. 판정자와 구현자가 같은 모델 계열이다. 독립성이 인격이 아니라 지시문과 도구 권한에서만 나오므로 공통 오류 모드는 공유될 수 있다. 좀비 리더 강등 판정 5라운드에서 라이브 미발동이 3차까지 반복된 사례(`docs/records/검토_판정기록.md` §4-1)가 그 한계의 실측이다.
- 일정 병렬화. 없다. 1인은 직렬이다. 역할 하네스가 만드는 것은 관심사 분리이지 처리량 증가가 아니다. 4인 팀이 40일에 할 일과 1인이 40일에 한 일은 같지 않다.
- ADR의 소급 작성. `0002`~`0013` 12편은 파일 타임스탬프가 2026-08-30이고 아직 커밋되지 않았다(`git status --short | grep -c '^?? docs/adr/'` -> 12). 헤더의 날짜 필드는 결정 시점이지 기록 시점이 아니다. 결정 당시의 판단을 그때 적은 것은 `0001` 하나뿐이고 나머지는 커밋 이력과 정본 문서에서 사후 재구성했다. 사후 재구성은 기억 보정이 섞일 수 있으므로 각 ADR은 근거를 커밋 해시와 파일 경로로만 달았다.
- 판정 대장의 부재. reviewer 반려 건수, 재검토 회차, 통과율을 집계할 수 있는 형태의 원장이 없다. `docs/records/검토_판정기록.md` 3절 18건은 커밋 이력에서 역추적한 표본이지 전수가 아니다.
- 역할 경계의 커밋 단위 이완. 다중 트리 커밋 131건은 한 커밋이 두 역할 범위를 동시에 건드린 경우를 포함한다(`docs/records/역할체계_운영기록.md` §4).
- 도구 권한 분리는 reviewer 하나에만 걸려 있다. 나머지 셋은 `tools` 필드가 없어 전체 도구를 상속한다. 구현 역할끼리는 서로의 트리를 고칠 수 있고, 그 경계는 지시문 준수에만 의존한다.
- 인수인계 리스크 미검증. 담당자가 사람이 아니므로 부재·이직·인수인계 상황에서 산출물이 읽히는지는 검증된 바 없다.

기각 대안 68건과 WBS 해시 314개는 파싱이 필요해 아래 스크립트로 셌다.
기각 대안은 `docs/adr/`가 미추적이라 작업 트리에서 세고, 커밋 축은 기준 해시에서 센다.

```bash
python -c "
import glob,io,csv,re,subprocess
t=0
for f in sorted(glob.glob('docs/adr/*.md')):
    inb=False
    for l in io.open(f,encoding='utf-8'):
        if l.startswith('## 대안'): inb=True; continue
        if inb and l.startswith('## '): inb=False
        if inb and l.startswith('- '): t+=1
print('기각 대안', t)                                        # 68
rows=list(csv.DictReader(io.open('제출_20260901/WBS.csv',encoding='utf-8-sig')))
h=set()
for r in rows: h|=set(re.findall(r'\b[0-9a-f]{7}\b', r['비고']))
full=set(subprocess.run(['git','rev-list','581d5f3'],capture_output=True,text=True).stdout.split())
short={x[:7] for x in full}
print('WBS 해시', len(h), '커밋', len(full), '미해석', len(h-short), 'WBS 미등장', len(short-h))
"        # WBS 해시 314 커밋 314 미해석 0 WBS 미등장 0
```
