# 개인 AWS 비용·연결 조회

2026-09-19 Chrome의 개인 계정을 조회했다. 자원 생성·삭제·설정 변경은 수행하지 않았다. 실제 화면 PNG와 접근성 텍스트는 같은 폴더에 보관하되 계정·크레딧 ID가 포함되어 Git에서 제외했다. 캡처 01~03은 크레딧 잔액·만료·기본 크레딧 적용 서비스, 04는 서울 EC2 대시보드, 05는 기본 VPC 대역, 06은 서울 ALB 0개 목록이다.

크레딧 예상 잔액은 $163.62, 활성 6개 표시 만료일은 2027-05-27이었다. 개인 서울 기본 VPC는 학교와 같은 172.31.0.0/16이므로 두 기본 VPC를 직접 피어링할 수 없다. 계정 전체 비용·모든 리전 자원·추가 크레딧별 상세 조건을 전수 확인한 결과가 아니다.

단가·월 계산·구성안·도메인 조회 결과는 [AWS 작업 안내](../../docs/reports/AWS_작업.md)의 한 달 운영 검토 절을 따른다. 공개 가격표에서 추출한 JSON과 DNS 명령 결과는 로컬 증거로 함께 보관한다. PC 터미널 화면은 캡처하지 못했다.
