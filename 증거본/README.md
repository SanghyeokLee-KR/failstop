# 실행 증거

AWS 설정과 Linux 명령 실행의 실제 화면·출력을 보관한다. 환경별로 날짜 폴더를 나누고 파일명 앞에 실행 순서 번호를 붙인다. 학교 계정과 개인 계정의 증거를 섞지 않는다. 현재 작업 상태는 [로드맵](../docs/ROADMAP.md)에서 관리한다.

화면에는 실행한 명령과 결과가 함께 보이게 한다. 긴 출력은 여러 장으로 나누고 원문 텍스트도 남긴다. 각 실행 기록에는 시간대, 대상 호스트, 명령, 결과와 캡처 파일명을 연결한다. 사용자의 2026-09-19 요청에 따라 터미널 명령 뒤에 종료 코드 출력용 문구를 붙이지 않는다. 도구가 종료 코드를 제공하면 별도 로그에 기록하고, 제공하지 않으면 미수집으로 표시한다. 성공 여부는 실제 출력·상태·검증 대상의 존재로 판단한다. 이전 종료 코드가 포함된 캡처는 당시 기록으로 보존한다. UI 조작은 설정 전후와 저장·생성 결과를 남긴다. 화면이 보이지 않는 도구 실행은 원문 로그로 표시하며 스크린샷으로 꾸미지 않는다.

비밀번호, MFA 코드·등록 QR, 개인 키, API 키, Teams 웹훅 주소, 세션 토큰은 기록하지 않는다. 비밀 입력 구간은 캡처에서 제외했다고 표시한다. 성공·실패·차단 결과를 구분하고, 캡처하지 못한 과거 실행은 재구성하지 않는다. 발표용 사본에 가림 처리가 필요하면 원본과 사본을 구분한다. 캡처는 인증 정보나 다른 사람의 자원이 없는지 확인한 뒤 공유한다.

- [2026-09-19 학교 AWS](2026-09-19_학교AWS/README.md): EC2·ASG 조회, 접근 거부, 보안 그룹 생성과 첫 서버 설정 화면.
- [2026-09-19 개인 AWS](2026-09-19_개인AWS/README.md): 개인 계정의 크레딧 잔액·만료, 서울 EC2·VPC·ALB 조회. 계정·크레딧 ID가 있어 캡처 원본은 Git에서 제외하고 README만 남긴다.
- [2026-09-20 시장 봇](2026-09-20_시장봇/README.md): BTC·ETH·XRP 기동, 용량 보호와 관제 접속 준비.
- [2026-09-20 백업·복구·보고](2026-09-20_백업_복구_보고/README.md): 격리 복원, DB 수동 승격·재편입, 앱·DB·디스크 경보와 Teams 보고.
- [2026-09-20 EC2_TEST 조회](2026-09-20_EC2_TEST_조회/README.md): 학교 계정 목록에서 확인한 다른 사용자의 인스턴스와 태그.
- [2026-09-20 SSH 키 등록](2026-09-20_SSH_키등록/README.md): 키페어 생성, 네 서버의 공개키 등록과 SSM 경유 SSH 인증.
- [2026-09-21 앱 무응답](2026-09-21_앱장애_행/README.md): app-1의 `/api/*` 504 진단, 스레드 덤프 두 번과 가상 스레드 해제 뒤 복구 확인. 진단용 임시 SSH 규칙의 제거 여부는 확인 기록이 없어 [AWS 작업 안내](../docs/reports/AWS_작업.md#2026-09-23-저장소와-학교-서버의-차이)에서 미확인으로 관리한다.
- [2026-09-26 VM pfSense](2026-09-26_VM_pfSense/README.md): 로컬 VM 실습망의 pfSense 설치·경계형 전환, 관리 키 재등록, 허용·차단 접속 시험과 차단 로그의 OPS01 원격 수신. AWS 검증 결과가 아니다.
- [2026-09-26 VM Databasus](2026-09-26_VM_Databasus/README.md): 로컬 VM 실습망의 Databasus 백업, 웹 진입 서버 SFTP로 서버 밖 보관, 복원 검증 에이전트 결과와 원본 대조. AWS 검증 결과가 아니다.
- [2026-09-27 학교 AWS 발표 자료](2026-09-27_학교AWS_발표서버/README.md): 발표 전용 보안 그룹·키 페어 준비, vCPU 한도로 인스턴스 시작 실패, 앱 서버 Nginx `/deck/` 게시와 공개 주소 확인.

PuTTY와 브라우저 터미널 중 실제 제어·캡처가 가능한 경로를 사용한다. 명령어 한 개를 실행한 뒤 출력과 결과를 보관하고 다음 명령으로 넘어간다. 접속 방법을 바꿨으면 해당 회차 기록에 표시한다. 이 폴더와 관련 설정·백업은 다른 PC로 옮길 수 있지만, 비밀 키와 비밀번호는 별도 안전한 경로로 관리한다.
