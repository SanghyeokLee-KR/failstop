# 학교 계정의 EC2_TEST 인스턴스 확인

2026-09-20 KST, 학교 계정의 2026-ai-kopo-04 사용자로 서울 리전 EC2 인스턴스 목록을 조회했다. 목록에 이 프로젝트가 만들지 않은 `EC2_TEST`가 보여 소유자를 확인했다. 조회만 수행했으며 연결·시작·중지·태그 변경은 하지 않았다.

목록의 실행 중 인스턴스는 다섯 대다. 이 프로젝트의 네 대는 `2026-ai-kopo-04-linux-lab-01`(i-0465dd41a0390f262), `2026-ai-kopo-04-db-primary-01`(i-0e302764af73d861f), `2026-ai-kopo-04-db-standby-01`(i-099799f0dc164ae71), `2026-ai-kopo-04-bot-01`(i-06ff9b16739362b14)이다. 나머지 `EC2_TEST`(i-0f284db92c5afa8b5)는 태그가 username `jpro`, group `admin`이므로 다른 사용자의 자원이다. 같은 날 [SSH 키 등록](../2026-09-20_SSH_키등록/README.md)에서 이 인스턴스를 대상에서 제외한 근거가 이 조회다.

| 자료 | 내용 |
|---|---|
| `01_상세.png`·`.txt` | 인스턴스 목록 다섯 대와 EC2_TEST의 세부 정보 탭 |
| `02_태그.png`·`.txt` | EC2_TEST 태그 탭의 username·Name·group 값 |

`.txt`는 브라우저 도구가 남긴 접근성 텍스트다. `02_태그.txt`의 일부 UI 라벨은 문자가 깨진 상태로 기록됐으므로 값의 기준은 같은 번호의 PNG로 확인한다. 깨진 원문을 다시 만들지 않고 당시 출력 그대로 보존한다.

두 캡처에는 학교 계정 ID와 EC2_TEST의 공인 주소가 함께 보인다. 발표나 제출 자료로 옮길 때는 가림 처리한 사본을 만들고 이 폴더의 원본과 구분한다. 다른 사용자의 자원이므로 접속하거나 설정을 바꾸지 않는다.

이 조회는 계정이 여러 사용자와 공유된다는 사실을 보여 준다. 인스턴스 대수·할당량·비용을 판단할 때 이 프로젝트의 네 대와 다른 사용자의 자원을 구분한다. 계정 전체의 자원 수와 할당량을 이번에 확정하지는 않았다.
