# 문서 색인

독자로 가른다. 폴더가 아니라 이 표가 분류의 정본이다. 폴더는 표를 따라 붙인 이름일 뿐이라
어긋나면 표가 이긴다. 경로는 `docs/` 기준 상대경로다.

상태는 둘이다. ACTIVE는 현재 유효한 정본, GENERATED는 다른 원본에서 뽑아낸 생성물이라
정본이 아니다. 생성물이라도 정본으로 지정된 것은 ACTIVE로 적고 원본을 비고에 밝힌다.

## 폐기 (`archive/`)

수명이 끝난 감사와 이력이다. **구현 근거로 인용하지 않는다.** 각 파일 첫 줄에 폐기 표시가 있다.

시점 기록으로 남기는 이유는 자가 감사를 반복했다는 사실 자체가 증거이기 때문이다.
지적이 전부 해소됐다는 것은 그 문서를 읽지 않아도 된다는 뜻이지 없었던 일이라는 뜻이 아니다.

`개선_백로그` `정밀감사_2차` `수정_작업목록` `최종_통합감사` `실서비스_준비도_감사`
`문서감사_리포트` `프로젝트_현황보고서` `NAMING` `AI_인수인계서_20260722`

`AI_인수인계서`는 커밋 제목 규칙을 명령형으로 적어 `CLAUDE.md`의 명사형 종결과 충돌했다.
그 문서를 먼저 읽은 에이전트는 스타일 게이트에 걸릴 커밋을 쓴다. 유효한 빌드 함정은
`실행_가이드.md` §7로 옮겼다.
