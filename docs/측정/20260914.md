## 5.7.17 접수 락 마켓별 분할 판정 B0·B4

ADR 0022 4단계의 판정 주행이다. 전역 접수 락(B0, main `5c9d986`)과 마켓별 접수 락(B4, `4bccb2a`)을 같은 날 같은 카오스 스택에서 요청 600/s 로 돌렸다. 판정 규약은 `docs/contracts/하네스_검증설계.md` §2-4 끝의 ADR 0022 4단계 B0·B4 판정 규약이고, 증거는 `harness/evidence/adr0022-stage4-b0b4-20260914/` 다.

**판정은 명제 성립이다.** 접수가 1.354배로 올랐지만 상한 A 1.531 이하이고, 락을 가른 뒤 전역 채번 카운터 행에서 대기가 보였다.

| 항목 | B0 | B4 |
|---|---:|---:|
| 접수/s | 112.45 | 152.25 |
| 접수 락 보유 점유(합) | 0.967 | 4.446 |
| 락 보유 1회(ms) | 8.597 | 29.179 |
| 머리말 1회(ms) | 3.522 | 23.294 |
| 커밋 1회(ms) | 4.319 | 4.874 |
| 커밋 동시성(T2) | 0.486 | 0.743 |
| 카운터 행 대기 표본 > 0 | 9회 중 0 | 10회 중 7(합 25) |
| fsync 건당(ms) | 3.239 | 2.932 |

- T1 비 1.354 는 평평 문턱 1.15 를 넘는다. A = 8.597 / ((0.929 + 4.874) x 0.967) = 1.531 이고 비가 A 이하다.
- 머리말 1회가 3.5ms 에서 23.3ms 로 늘었다. 마켓별 락 안에서 12개 append 가 채번 카운터 행을 기다린다는 뜻이고, 표본기가 같은 대기를 잡았다. 분류기 양성 대조는 두 칸 모두 PASS 다.
- 양성 축을 모두 채웠다. 12마켓 각 접수 0 초과, `k6_rc` 0, append 풀 대기 0, 연결 최대 65·56(한도 197)이다.
- T2 는 두 칸 모두 PASS 이고 N/A 가 아니다.

**비교하지 않는 것.** 이날 fsync 건당이 3.2ms 대로 5.7.14(2026-09-13, 0.46ms 대)보다 느렸다. B0 접수 112.45/s 를 5.7.14 의 272/s 와 나란히 놓지 않는다. 같은 날 B0·B4 비만 판정에 쓴다.

**재지 않은 것.** 클라우드 스택, 한 마켓 쏠림, 래치 뒤 마켓별 채번(6단계)이다. 주행은 로컬 한 번이다.

## 5.7.18 5단계 장애 주행 E2·E4·E5·E6·E7

ADR 0022 5단계다. 4단계 B4 이미지(`4bccb2a`)로 페일오버 실험 다섯을 실험마다 새 스택에서 한 번씩 돌렸다. 절차는 `harness/scripts/adr0022-stage5-chaos.ps1`, 증거는 `harness/evidence/adr0022-stage5-20260914/` 와 `harness/evidence/chaos-runs/` 의 2026-09-14 판정 파일 다섯이다.

**다섯 모두 실험 판정 PASS 다.**

| 실험 | RTO(초) | rpo_records | C22 두 팔 | created_at 역행 |
|---|---:|---:|---|---:|
| E2 DB 연결 절단 | 10.507 | 0 | 0, 0 | 0 |
| E4 리더 kill | 5.866 | 0 | 0, 0 | 0 |
| E5 네트워크 분리 | 10.079 | 1 | 0, 0 | 0 |
| E6 부하 급증 중 kill | 5.277 | 0 | 0, 0 | 0 |
| E7 리더 pause | 10.024 | 0 | 0, 0 | 0 |

- 다섯 실험 모두 epoch 가 1 에서 2 로 오르고 리스 보유자가 바뀌었다. 연결 고갈은 없었다.
- 마켓별 동시 append 뒤에도 사후 창 C22 두 팔과 마켓 안 `created_at` 역행이 0 이었다.
- E5 의 `rpo_records` 1 은 유실이 아니다. E5 는 드레인 없이 사후 run 의 C13A 를 rpo 에 더하는데, 그 1 은 물질화를 기다리던 주문 생성 명령이고 1.4초 뒤 채집한 하네스 SQL 에서 0행이었다. 같은 run 의 C16, C05, C06 은 0 이다.
- E5·E7 은 도커 사건 수집이 주입보다 늦게 시작해 주입 사건(disconnect, pause)이 기록에 없다. 복귀 사건(connect, unpause)과 승격으로 간접 확인했다.

**재지 않은 것.** 클라우드 스택, 커널 계층 주입(E10), 실험별 반복이다. E5 rpo 측정의 드레인 결함과 사건 수집 시작 시점은 후속으로 고친다.
