# 고가용성 가상 암호화폐 거래소 · 최종 디자인 시스템 문서 (v1.1, 구현 착수판)

> 본 문서는 토큰 초안·화면 초안·비평(JSON, 73점)을 종합하고, 비평의 **critical 1건·high 3건·medium 4건·low 3건 전부**를 반영해 확정한 단일 소스다. 값·이름 충돌을 제거해 `tokens.css` 하나를 **계약(contract)** 으로 고정했다. 색은 항상 시맨틱 토큰으로 소비한다(primitive 직접 사용 금지).
>
> 스택: Next.js(App Router)+TypeScript / Spring REST·WebSocket(STOMP). 폰트: 오픈폰트 **Pretendard**. 산출물 언어: 한국어(토큰·기술명은 영어).

---

## 0. 디자인 원칙 (전 화면 불변 규약)

1. **한국 시장 관례 절대 준수. 상승/매수 = Red, 하락/매도 = Blue.** 전 화면·차트·호가·손익에 강제. 반전 금지.
2. **방향은 색 단독 표현 금지.** 반드시 `색 + 부호(+/−) + 화살표(▲▼)` 병기 → 적록색약·명도 저하 상황 보정.
3. **가격 방향에 green 금지.** green은 시스템 성공(체결완료 등) 전용.
4. **하락-Blue ≠ 브랜드-Blue.** 링크/버튼(브랜드)과 하락 숫자를 hue·명도로 분리. **다크에서도 동등한 gap 유지**(초안이 붕괴시킨 지점 → 본 문서에서 다크 down을 cyan-lean으로 재조정). 링크는 색 외 밑줄 등 비색 단서 병행.
5. **접근성 대비 실패 지점(초안의 critical) 해소**. 방향색을 **면/대형용(`--color-up`)** 과 **텍스트용(`--color-up-text`, 600단계)** 으로 분리. 소형 숫자·CTA 텍스트는 4.5:1 이상 확보.
6. **숫자는 `tabular-nums` + `Intl.NumberFormat('ko-KR')`** + 컨테이너 폭 고정 → 실시간 갱신 시 레이아웃 시프트 0.
7. **오리지널리티**. 토스의 상표/로고/브랜드명("토스" 등)·독점 자산 미사용. 토큰 값·카피 보이스는 본 문서의 오리지널 정의만 사용(§10·§10-1). Pretendard(오픈폰트) 사용.
8. **모바일 퍼스트**(기준 폭 360~390px, safe-area 대응), 넉넉한 여백·큰 볼드 숫자·라운드 16~20px·부드러운 모션. 카피는 §10-1 보이스 규정(개조식 명사 종결)을 따른다.

## 2. 시맨틱 토큰 · 라이트 (`:root`)

```css
:root{
  color-scheme:light;

  /* ===== Background / Surface =====
     페이지 바닥은 bg-muted 하나다. §6.4가 --surface-seam:var(--bg-muted)로 이음새를 같은 면에
     맡기면서 --bg-base가 설 자리가 없어졌다(라이트에서 surface-default와 동값이라 패널 경계도
     못 만든다). 소비처 0으로 남아 있던 선언을 v1.7에서 걷어냈다 */
  --bg-muted:var(--grey-50);
  --surface-default:#FFFFFF; --surface-sunken:var(--grey-100);
  --surface-hover:var(--grey-100); --surface-elevated:#FFFFFF;
  /* 컨트롤 면(v1.5). sunken 행 위 버튼이 형태를 유지하도록 sunken보다 한 단계 진하다.
     hover와 같은 값을 쓰면 라이트에서 버튼이 배경에 묻히고 hover가 no-op가 된다 */
  --surface-control:var(--grey-200); --surface-control-hover:var(--grey-300);
  /* select 자체 셰브런(v1.5). appearance:none으로 걷어낸 OS 화살표의 토큰 대체.
     색은 grey-600(라이트)·text-secondary 실값(다크) 유래의 인라인 SVG data URI */
  --select-chevron:url("data:image/svg+xml;utf8,<svg ...>");

  /* ===== Border ===== */
  --border-subtle:var(--grey-200); --border-default:var(--grey-300); --border-strong:var(--grey-400);
  /* secondary 버튼 경계(v1.6). 라이트는 sunken 면이 카드와 명도로 갈려 경계가 형태 보조라 default(1.41:1).
     다크는 면 대비 1.06:1이라 경계가 유일한 식별 채널이고 3:1(1.4.11)을 넘는 전용값을 쓴다 */
  --btn-secondary-border:var(--border-default);

  /* ===== Text ===== */
  --text-strong:var(--grey-900);   /* 제목·큰 숫자 */
  --text-default:var(--grey-800);  /* 본문 */
  --text-secondary:var(--grey-600);/* 정보 전달용 캡션/라벨 최소선. on #FFF 4.75:1 / on --surface-sunken(#F1F3F5) 4.27:1 미달 → sunken 위 정보 라벨은 --text-default 사용(§9) */
  --text-tertiary:var(--grey-500); /* 장식/비활성만, 정보 전달 금지 */
  --text-disabled:var(--grey-400);
  --text-inverse:#FFFFFF;
  --text-brand:var(--brand-600);   /* 링크 텍스트 (600으로 대비 확보) */
  --text-on-brand:#FFFFFF;
  /* 코인 브랜드칩 온-브랜드 텍스트(v1.4). 칩 배경은 데이터(brandColor)라 앱 테마와 무관하게 고정.
     접미사 light·dark는 텍스트 밝기 기준(앱 테마 아님): light=밝은 글자, dark=어두운 글자.
     다크 테마 블록에서 재정의하지 않는다. */
  --text-on-brand-light:#FFFFFF;   /* 어두운 브랜드 배경 위 */
  --text-on-brand-dark:#16191F;    /* 밝은 브랜드 배경 위 */
  /* 둘 중 무엇을 쓸지는 수기 지정이 아니라 브랜드색 휘도 계산이 정한다(lib/brandChip.ts).
     칩 모노그램은 10~12px이라 large-text 예외 밖이고 4.5:1이 필요하다.
     흰·검 어느 쪽도 4.5:1을 못 넘는 브랜드색(예: AVAX #E84142, 흰 3.99·검 4.41)은
     선택한 라벨의 반대 극으로 배경 명도를 최소 보정해 확보한다. */

  /* ===== Brand / Interactive ===== */
  --brand-primary:var(--brand-600);         /* 텍스트/보더에 안전한 기본 */
  --brand-primary-fill:var(--brand-500);    /* 큰 면(버튼 배경) */
  --brand-primary-hover:var(--brand-600);
  --brand-primary-pressed:var(--brand-700);
  --brand-weak-bg:var(--brand-50);

  /* ===== 시장 방향색 · 면/대형 vs 텍스트 분리 (critical 반영) ===== */
  /* 면·히어로(large-text ≥24px/700 또는 배경 틴트) 전용 */
  --color-up:var(--red-500);        --color-down:var(--azure-500);
  --color-up-bg:var(--red-50);      --color-down-bg:var(--azure-50);
  --color-up-flash:rgba(242,54,69,.10);   /* #F23645 파생, 값 통일 */
  --color-down-flash:rgba(28,130,232,.10);/* #1C82E8 파생, 값 통일 */
  /* 소형 텍스트(캡션/바디/미세 숫자) 전용. 흰/기본 surface 기준 4.5:1 이상.
     틴트(-bg) 위 소형 텍스트는 -text가 아닌 -strong(700) 사용:
     red-600 on red-50 4.22:1 미달 / red-700 on red-50 5.53:1 / azure-700 on azure-50 6.73:1 */
  --color-up-text:var(--red-600);   /* on #FFF 4.82:1 */
  --color-down-text:var(--azure-600);/* on #FFF 5.27:1 */
  --color-up-strong:var(--red-700); --color-down-strong:var(--azure-700);
  --color-flat:var(--grey-600);     /* 보합. 무채색, 화살표 없음 */

  /* 주문 CTA. 라벨은 --text-inverse. 라이트: fill 면 위 흰 텍스트 4.5:1 확보 → 600단계(4.82/5.27:1).
     다크는 600단계가 아닌 전용값 + #16191F 라벨(§3 주석 참조) */
  --color-buy:var(--red-600);          --color-buy-pressed:var(--red-700);
  --color-sell:var(--azure-600);       --color-sell-pressed:var(--azure-700);

  /* ===== 시스템 시맨틱 ===== */
  /* 600 원색은 아이콘·점·면·보더 전용. 소형 텍스트 대비 미달(green-600 on #FFF 4.27:1, orange-600 3.09:1).
     소형 텍스트는 반드시 -text 사용(틴트 -bg 위 포함 4.5:1 확보). */
  --color-success:var(--green-600);  --color-success-bg:var(--green-50);
  --color-success-text:var(--green-700);   /* on #FFF 5.81:1 / on green-50 5.24:1 */
  --color-warning:var(--orange-600); --color-warning-bg:var(--orange-50);
  --color-warning-text:var(--orange-800);  /* on #FFF 6.50:1 / on orange-50 5.98:1 (orange-700은 틴트 위 4.18:1 미달) */
  --color-danger:var(--crimson-600); --color-danger-bg:rgba(194,48,76,.08);
  --color-info:var(--brand-600);     --color-info-bg:var(--brand-50);
  /* 시스템 헬스 상태 전이 플래시(화면7 전용). 시세 플래시(--color-up/down-flash)와 도메인 분리, 차용 금지 */
  --color-health-flash-success:rgba(11,140,93,.10);  /* green-600 #0B8C5D 파생 */
  --color-health-flash-warning:rgba(219,122,0,.10);  /* orange-600 #DB7A00 파생 */
  --color-health-flash-danger:rgba(166,30,60,.10);   /* crimson-600 #A61E3C 파생 */

  /* ===== Overlay / State / Focus ===== */
  --overlay-dim:rgba(15,23,42,.55);
  --pressed-layer:var(--grey-alpha-100);
  --skeleton-base:var(--grey-100); --skeleton-shine:var(--grey-50);
  /* 이중 포커스 링(v1.7). 바깥 링은 outline, 안쪽 헤어라인은 inset box-shadow.
     v1.6까지 양쪽 다 box-shadow였으나 스크롤 컨테이너(호가·마켓·자산 리스트) overflow 경계에서
     바깥 링이 잘렸다. outline은 클리핑되지 않고 offset 간격이 surface 분리 역할을 한다.
     비색 단서 병행, 인접 대비 ≥3:1. 오류 링은 --focus-outline-color만 덮어쓴다.
     outline 축약형은 토큰에 조립하지 않는다. var() 치환이 선언 지점에서 끝나 색이 굳는다.
     조립은 소비 규칙(globals.css :focus-visible·.focus-ring-owner)이 한다 */
  --focus-outline-width:2px;
  --focus-outline-color:var(--brand-primary);
  --focus-outline-offset:2px;
  --focus-inner:inset 0 0 0 1px var(--surface-default);

  /* 스크롤바(v1.7). OS 기본 스크롤바는 화면에서 가장 시끄러우면서 토큰이 소유하지 않는
     유일한 요소였다. 트랙을 비우고 썸만 무채로 남겨 정숙 계기 어휘에 편입한다.
     썸은 컨테이너 배경(surface-default) 대비 3:1 이상(1.4.11 UI 컴포넌트).
     실측: grey-500 on #FFFFFF 3.03:1(grey-400은 1.94:1 미달) / 다크 grey-600 on #171A21 3.67:1 */
  --scrollbar-thumb:var(--grey-500);   /* 다크 --grey-600 */
  --scrollbar-track:transparent;
}
```

## 7. 컴포넌트 인벤토리 (16종 + 파생)

각 항목: 용도 / 변형 / 상태 / 사용 토큰. 모든 토큰명은 §1~5 계약 이름.

**A-1. AppBar**. 최상단 타이틀/뒤로가기/우측 액션. 변형 `default·back·large·transparent`. 상태 `rest·scrolled`(하단 `--border-subtle` 1px + 미세 `--shadow-1`). 토큰: 높이 56px, 좌우 `--layout-gutter`, 타이틀 `--font-title-3`, 배경 `--surface-default`.

**A-2. TabBar** (하단 글로벌 네비, 오리지널 정의). 5탭(홈/마켓/주문/자산/더보기). `active`(아이콘 fill + 라벨 `--brand-primary`, 600 수식은 라이트 한정, 다크는 전용값 #6B9DF7) / `inactive`(line + `--text-secondary`) / `badge`. 높이 56px + `env(safe-area-inset-bottom)`, 아이콘 24px, 라벨 `--font-micro`, 상단 `--border-subtle`. 히트영역 ≥48px, `aria-current="page"`.

**A-3. > 모든 색 참조는 §2·6 계약 이름. 소형 방향 숫자는 `-text`, 히어로는 `-500`.

### 화면 1. 온보딩 / 로그인
- **구조:** 풀스크린 단일 컬럼. 히어로 → 여백 → CTA 스택. 뷰포트 세로 중앙 정렬(v1.7).
  초안의 "하단 고정 CTA"는 모바일 우선 시절 표기다. 고정형 데스크톱에서는 하단 고정이 히어로와
  CTA 사이를 화면 높이만큼 벌려 한 덩어리로 안 읽힌다.
- **위계:** 아이덴티티 → 진입 CTA → 보조(약관·둘러보기).
- **배치(v1.7):** 공개 내비 없음. 온보딩은 진입 게이트라 헤더가 홈·거래소 링크를 열면 게이트를
  우회하고 로그인·가입 링크가 본문 CTA와 중복된다. 테마 토글만 남긴 투명 바를 둔다.
  히어로 마크(계기 명판) + `--font-display-lg` + 서브카피(`--font-body` `--text-secondary`) /
  `Button full primary`("회원 가입") + `Button full secondary`("로그인 없이 둘러보기") / 약관 `--font-caption`.
  제목이 `--font-title-1`(24px)이던 초안은 모바일 히어로 기준이라 1280px 화면에서 본문 CTA
  라벨(17px) 대비 위계가 서지 않는다.
- **보안 규칙:** 실제 계정 생성·비밀번호 입력·인증은 **사용자 직접**. 여기선 UI 스펙만.
- **상태:** 로딩=CTA `loading`(폭 고정). 에러=진입 실패·네트워크 오류 → `Toast error` §10-1 보이스("접속 실패. 잠시 후 다시 시도 필요"). 진입=히어로 페이드+슬라이드업 `--ease-emphasized`. (이메일 등 입력·인증 UI는 본 화면에 없음, 위 보안 규칙에 따라 별도 인증 플로우로 이관.)
- **모바일:** CTA safe-area 하단 고정(본 화면은 입력 필드가 없어 키보드 대응 불요).

## 9. 접근성 체크리스트 (구현·QA 겸용)

**색 대비 (WCAG 1.4.3 / 1.4.11)**
- [ ] 방향 **소형 텍스트**(현재가·등락률·손익, caption/body/micro)는 흰/기본 surface 위에서 `--color-up-text`(red-600 4.82:1)·`--color-down-text`(azure-600 5.27:1) 사용. **500단계 텍스트 금지**.
- [ ] `--color-up`/`--color-down`(500)은 `--font-display-*`(≥24px/700) 히어로와 배경 틴트에만.
- [ ] 틴트(`-bg`) 위 소형 텍스트는 `-strong`(700). up-strong on up-bg 5.53:1 / down-strong on down-bg 6.73:1 (`-text` 600은 up-bg 위 4.22:1 미달).
- [ ] 매수/매도 CTA 라벨은 `--text-inverse`. **라이트:** 흰 텍스트 on 600단계(`--color-buy` 4.82:1 / `--color-sell` 5.27:1), **다크:** `#16191F` on 다크 전용값(5.87/6.75:1). 다크에서 흰 CTA 라벨 금지(3.00/2.61:1 미달). '600단계'는 라이트 한정.
- [ ] 정보 전달용 캡션/라벨은 `--text-secondary` 이상. 요구 최소선 4.5:1, 실측: 라이트 grey-600 on #FFF 4.75:1(**단, on `--surface-sunken` #F1F3F5 4.27:1 미달, sunken 트랙/칩 위 정보 라벨은 `--text-secondary` 금지, `--text-default` 사용(on sunken 11.1:1); A-9 unselected·A-10 rest 칩 적용**) / 다크 #A8B2BE 8.11:1(최악 elevated #232833 기준 6.87:1, sunken #12141A 8.57:1, 다크는 전 surface 통과). `--text-tertiary`(다크 실측 5.68:1)는 장식·비활성만. (틴트 위 `-strong` 승격과 동일 패턴의 최악 surface 규칙.)
- [ ] 다크 방향색(up #FF5D63 5.80:1 / down #35A6FF 6.67:1)·brand 텍스트(#6B9DF7 6.46:1) surface 대비 ≥4.5:1, 다크 primary fill(#3D6DDB)은 흰 라벨 4.76:1 재검증(자동화).
- [ ] 시스템 시맨틱 소형 텍스트는 `-text` 사용. 라이트 success=green-700(5.81:1)·warning=orange-800(6.50:1); 600 원색 텍스트 금지(4.27/3.09:1 미달).
- [ ] UI 컴포넌트/포커스 링 인접 대비 ≥3:1. 이중 링(`--focus-outline-width`/`-color` + `--focus-inner`, 불투명 브랜드 + surface 오프셋).

**색 외 단서 (1.4.1)**
- [ ] 방향은 색 + 부호(+/−) + 화살표(▲▼) 병기. 보합(flat)은 무채색·화살표 없음.

- [ ] StatusPill·시스템 헬스는 색 + 아이콘 + 라벨(색 단독 금지).

**하락-Blue ≠ 브랜드-Blue**

## 10. 오리지널리티 주의 (필수)

- 토스의 **상표·로고·브랜드명("토스" 등)·독점 자산·저작 일러스트·스쿼클 자산을 복제하지 않는다.** 여백·큰 볼드 숫자·라운드·부드러운 모션 같은 질감은 품질 참고에 그친다. 토큰 값과 카피 보이스(§10-1)는 본 문서의 오리지널 정의를 사용하며, 레퍼런스 말투를 가져오지 않는다.
- 브랜드 블루는 토스 시그니처(#3182F6)와 hue·명도를 분리한 독자값(#2E6BE6)이다.
- 폰트는 오픈폰트 **Pretendard**만 사용(라이선스 준수).
- 마이크로카피·일러스트는 자체 제작하며, 외부 브랜드 문구를 인용하지 않는다.

### 10-1. 보이스 · UI 카피 규정

고객 평면의 시각 노출 카피는 단일 보이스를 쓴다. 해요체·합쇼체 혼용은 리뷰 반려 사유다.

- **기본형은 개조식 명사 종결.** 완료 통지 "주문 취소 완료", 빈 상태 "기록 없음", 안내 "로그인 필요".
- **행동 지시는 명령형 축약.** "실계정 정보 입력 금지", "첫 코인을 담아 포트폴리오 시작".
- **해요체·합쇼체 금지.** "취소했어요"·"취소했습니다" 모두 불가. 에러 문구도 같은 보이스: "잔고 부족", "입력값 확인 필요". 재시도 안내는 "잠시 후 다시 시도 필요"로 통일.
- **예외 1: 낭독문.** sr-only·aria-label·aria-live 텍스트는 화면 카피가 아니라 보조기술 문장이므로 자연스러운 서술("~합니다" 포함)을 유지한다.
- **예외 2: 짧은 의문형 확인.** 파괴적 액션 직전 인라인 확인("삭제할까요?")과 전환 유도 질문("이미 회원이신가요?")은 의문형을 허용한다.
- **불변.** 도메인 용어·계약 문자열(에러 코드, API 필드, 서버가 본문으로 내려주는 문자열)은 보이스 치환 대상이 아니다.

### 10-2. 탭 타깃 규정 · 플랫폼별 밀도

44x44px 히트 영역은 손가락 입력 기준이다. 이 제품은 고정형 데스크톱 전용(최소 1280px, 반응형 리플로우 없음)이라 전 컨트롤에 44px 시각 높이를 강제하면 고밀도 판독 존이 무너진다.

- **기본 규칙 유지.** 버튼·링크·폼 컨트롤 등 단발 조작 요소는 히트 영역 ≥44x44px. 시각 높이가 32~40px이면 투명 `::after`로 히트만 확장한다(인접 gap 안에서만, 겹침 금지). 조작 버튼의 시각 높이 하한은 32px이며 그 아래는 허용하지 않는다.
- **밀도 예외(데스크톱 한정).** 마우스 포인터 전제의 고밀도 판독 행은 시각 높이 32~36px을 허용한다. 대상: 호가 행(32px), 체결 테이프 행(28px), 감사 로그 행(36px). 근거는 정밀 포인터 입력과 행 밀도가 판독 성능의 주 채널이라는 점이며, 오조작 방지는 히트 확장이 아니라 **프리필 후 확인 단계**가 담당한다(호가 탭은 즉시 확정이 아니다).
- **모바일 전개 시.** 모바일 화면을 만들면 위 예외는 무효다. 호가 행 44px 상향 등 §11 medium 항목의 원래 처방을 그대로 적용한다.
