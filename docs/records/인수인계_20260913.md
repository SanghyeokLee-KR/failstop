## 7. 오늘 검토가 잡은 결함 둘 (교훈)

둘 다 내가 만든 새 코드가 검증 도구 자체를 망가뜨릴 뻔한 경우다.

1. **WP10 커밋 본문이 시험 수정 전 빌드 결과(591건)를 최종 증거로 적을 뻔했다.** 파일 수정

2. **계층 프로브·경보 수정 둘 다에서 새 promtool 시험 픽스처가 `rule_files` 글롭에 걸려

   다른 층이라는 것을 실측(exit 2)으로 확인하고서야 닫혔다. **다음에 promtool 시험 파일을
   새로 만들 때는 `rules/` 가 아니라 별도 디렉터리에 두고, `check config` 를 반드시 같이
   돌린다.**
