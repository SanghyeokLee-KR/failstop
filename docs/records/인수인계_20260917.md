## 0. 이 저장소를 읽는 AI 에게

- 우선순위는 `CLAUDE.md` > `docs/` 정본(`docs/README.md` 가 ACTIVE 로 적은 것) > 코드 > 요약 문서다.
  정본끼리 어긋나면 한쪽을 골라 추측하지 말고 어긋남 자체를 보고한다.
- 수치를 인용할 때는 증거 경로(`harness/evidence/...`, `docs/측정/...`)를 함께 적는다.
  경로 없는 수치는 미확인으로 다룬다.
- 클라우드 실측은 0건이다. 모든 카오스·부하 수치는 단일 PC 로컬 도커 스택 값이다.
- 다음 표현은 사실이 아니다. 쓰지 않는다.
  - DB 자동 페일오버. PostgreSQL 승격은 사람이 하는 수동 절차다(ADR 0024, `docs/operations/DB_수동_페일오버.md`).
    자동인 것은 애플리케이션 리더 전환뿐이다(ADR 0002).
  - 비동기 복제 무손실, "저널 재생으로 RPO 0". RPO 는 복제 지연과 같다.
  - DB 2대 쓰기 확장. standby 는 조회 라우팅도 없다.
- `docs/archive/`, 루트 `README.md`, `docs/architecture/아키텍처_개관.md` 는 현재 근거가 아니다(5절).

## 1. 프로젝트 한 장

- 1인 캡스톤. 고가용성 가상 암호화폐 거래소. 실거래·실자산 없음. 최종 발표 2026-10-16.
- 증명 명제 둘(`CLAUDE.md` 0절).
  1. 체결 무결. 폭주와 장애에도 자산별 원장 합 0, 주문 중복·유실 0.
  2. 자동 복구. 사람 개입 없이 리더 승격, RTO 30초 이내, epoch 정확히 +1.
- 판정 주체는 사람 눈이 아니라 SQL 위반 행 수, 메트릭 임계, 스크립트 종료코드다.
- 구성.
  - `server/engine`: Spring 의존 없는 순수 Java 매칭엔진. 결정론 코어.
  - `server/app`: Spring Boot. REST·WebSocket, 명령·이벤트 저널, 원장, 리더 리스와 fencing, 스냅샷, 봇 플릿, 불변식 검증기.
  - PostgreSQL 17. 모든 쓰기는 `assert_current_leader(holder, epoch)` 를 통과해야 커밋된다(`CLAUDE.md` 14절).
  - `web`: Next.js 정적 export 데스크톱 화면.
  - `harness`: 카오스 스택(도커 컴포즈, Toxiproxy), 부하(k6·봇), 관측(Prometheus·Grafana·Alertmanager·blackbox), 불변식 SQL.
  - `deploy`: AWS 노드별 컴포즈. 다중 호스트 기동 0건.
- 평면 셋. 상시면(AWS 24시간), 증명면(AWS 실험 창), 검증면(온프레미스 로컬 도커). 파괴 실험은 검증면에서
  수렴시키고 확정 회차만 AWS 에서 재현한다(ADR 0010 결정 3).

## 6. 미결 결정

- **학교 AWS 계정 리소스 제한.** 학교가 NAT Gateway, Route 53, ACM, Systems Manager, IAM, KMS, AWS Budgets,
  Cost Explorer 사용을 기본 제한했다(2026-09-16 통보). Budgets·Cost Explorer 는 콘솔 청구 화면으로 대체하고
  나머지 여섯은 교수님께 허용을 요청 중이다. 설계 영향.
  - IAM·SSM: 인스턴스 역할과 Session Manager 접속(`CLAUDE.md` 18절)이 여기에 걸린다. 막히면 SSH 와 운영자 IP
    한정 보안그룹으로 바꿔야 한다.
  - ACM: CloudFront·ALB HTTPS 인증서. 막히면 엣지 nginx 와 Let's Encrypt 로 돌아간다.
  - NAT Gateway: ADR 0020. 막히면 NAT 인스턴스로 되돌린다.
  - Route 53: 가비아 DNS 는 루트 도메인 CNAME·ALIAS 를 지원하지 않고 CloudFront·ALB 는 고정 IP 가 없다. 막히면
    서비스 주소를 서브도메인으로 바꾸거나(`deploy/.env.example` 오리진 값과 웹 빌드값 `NEXT_PUBLIC_WS_BASE` 변경)
    Cloudflare DNS 의 CNAME 평탄화를 쓴다.
  - KMS: 고객 관리형 키는 쓰지 않는다. AWS 관리형 키 사용까지 막히는지는 미확인이다.
- **클라우드 배포 착수 시점.** 지원금 확정에 묶여 있다.
- **클라우드 정본 복원 위치.** 5절 1항.
