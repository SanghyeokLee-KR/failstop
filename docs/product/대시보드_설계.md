# 홈 대시보드 설계

거래소 홈 랜딩(시장 개관). 고정형 데스크톱 전용. tokens.css만 소비하고 DataSource 인터페이스로만 데이터에 접근한다. 특정 서비스(증권 대시보드 등)는 품질 레퍼런스일 뿐 레이아웃·색·문구를 복제하지 않는다. 암호화폐 대시보드이며 주식 지표(코스피·나스닥 등)를 넣지 않는다.

정본: docs/contracts/프론트_디자인시스템.md(토큰), docs/contracts/데스크톱_레이아웃설계.md(고정형 그리드·HeaderNav·PanelCard 패턴), docs/contracts/백엔드_API_설계.md(데이터 계약).

## 1. 라우팅

홈 대시보드를 루트 랜딩으로 둔다.

| 라우트 | 처리 | 근거 |
|---|---|---|
| `/home` | 대시보드 본체(신설). `page.tsx`(서버 셸, metadata) + `DashboardClient.tsx`(본체) | 명시적 정적 경로. 거래 화면(`/exchange`)과 랜딩을 분리해 각 화면의 존재 이유를 명확히 한다 |
| `/` | `/home`으로 클라이언트 replace(기존 `/exchange` 대상 교체) | 정적 export라 서버 redirect 불가. 기존 리다이렉트 패턴 재사용 |

- HeaderNav 첫 항목에 `홈`(→`/home`)을 추가하고 로고 링크를 `/exchange`에서 `/home`으로 옮긴다. 기존 항목(거래소·자산·거래내역·시스템 상태)은 유지한다.
- `generateStaticParams`와 정적 export를 유지한다. `/home`은 정적 페이지로 산출된다.
- `/exchange` 인덱스 리다이렉트(최근 마켓 복원)와 구 딥링크 경로는 건드리지 않는다.

대안으로 `/` 리다이렉트 대상만 대시보드로 바꾸는 방법이 있으나, 별도 경로(`/home`)를 두면 로고·내비·딥링크가 랜딩을 명시적으로 가리켜 IA가 단순해진다. 그래서 `/home` 신설을 택했다.

## 2. 화면 구성과 그리드

`max-width: 1440px` 중앙 컨테이너, 좌우 패딩 `--layout-gutter`. 랜딩이므로 페이지 세로 스크롤을 허용한다(거래 화면의 무스크롤 원칙과 무관).

```
grid-template-columns: minmax(0, 1fr) 320px;
grid-template-areas:
  "summary   summary"
  "spotlight watch"
  "ranking   ranking";
```

- summary(전폭): MarketSummaryStrip
- spotlight(좌): SpotlightPanel
- ranking(전폭): RankingTable. 6열이라 좌열 폭으로는 열 여유가 부족하다
- watch(우, 1행): WatchlistSidebar. 2행 관통은 목록이 짧을 때 페이지 하단에 대면적 공백을 남긴다

각 패널은 전역 `.card`(surface + radius-lg + shadow-1, 다크 border) 위에 자체 레이아웃을 얹는다.

## 3. 패널별 데이터 매핑

전 패널 공통: 상승 Red·하락 Blue, 방향은 색 단독 금지(부호+화살표 병기). 숫자는 `.num` tabular + `Intl.NumberFormat('ko-KR')`. 실시간 갱신 레이아웃 시프트 0.

| 패널 | 데이터 소스 | 내용 |
|---|---|---|
| MarketSummaryStrip | `tickers`(전 마켓 집계) + `getCandles`(대표 코인 추세) | 24H 총 거래대금 = Σ`acc_trade_price_24h`, 상승·하락·보합 코인 수(`change` 집계). 대표 코인(로스터 상위 4) 미니 카드: 현재가·등락·Sparkline |
| RankingTable | `tickers` | 탭 3종. 거래대금순=`acc_trade_price_24h` 내림차순, 급상승=부호 있는 등락률 내림차순, 급하락=오름차순. 열: 순위·코인·거래대금 점유 막대·현재가(TickCell)·전일대비(▲▼ 병기)·거래대금 축약 6열. 점유 막대는 1위 대비 상대값이며 **무채(--border-strong)·aria-hidden 보조 채널**이고 판독의 주 채널은 우측 거래대금 텍스트다(방향색 금지). 슬랙을 우측 정렬 숫자 열에 주면 이름과 수 사이가 벌어지므로 가운데 막대 열이 흡수한다. 행 클릭 → `/exchange/[market]` |
| SpotlightPanel | `tickers[선택]` + `getCandles` | 대표 코인 칩 선택(대시보드 로컬 상태), 주기 탭(15분·1시간·1일), CandleChart 재사용, 요약(고·저·거래량), 거래 화면 CTA |
| WatchlistSidebar | `favorites`(localStorage) + `tickers` | 관심 코인 리스트. 비면 거래대금 상위 6종으로 대체하고 안내 노출. 비지 않아도 6행 미만이면 비관심 거래대금 상위로 채우고 "거래대금 상위" 명판으로 구간을 가른다(레일 공백 방지). 행 클릭 → `/exchange/[market]` |

- 등락률 색·부호·화살표: RankingTable·WatchlistSidebar·SummaryStrip 대표 카드 모두 `formatDirectional`(▲▼ + 부호)과 `dir-text`(소형 텍스트 -text 600) 사용.
- Sparkline: `getCandles(market, "15m", 24)` 종가 배열을 SVG path로 그린다. 색은 방향 토큰(`dir-hero` 경로, --color-up/down/flat)만 소비.

## 4. 컴포넌트 구분

신규(`web/components/dashboard/`):

| 컴포넌트 | 책임 |
|---|---|
| Sparkline | 종가 배열 → 미니 추세선 SVG. 방향 토큰 색 |
| MarketSummaryStrip | 전체 집계 + 대표 코인 미니 카드 |
| RankingTable | 탭 정렬 순위 테이블 |
| SpotlightPanel | 대표 코인 캔들 + 요약 + CTA |
| WatchlistSidebar | 관심(없으면 인기) 코인 리스트 |

재사용(무수정): CandleChart, SegmentedTab, SymbolChip, TickCell, PricePill, format 유틸, store(`useLiveChannels`·selector), DataSource. 신규 컴포넌트는 기존 인벤토리와 책임이 겹치지 않는다(대시보드 밀도·순위·집계는 거래 화면 패널과 별개 표현).

## 5. 코인 로스터 확장

대시보드 순위·집계가 풍부해지도록 `lib/sim/engine.ts`의 시뮬레이터 시드를 6종에서 12종으로 확장한다. sim(프론트) 전용이며 백엔드는 건드리지 않는다. http 모드에서는 백엔드 마켓만 노출되며 이 목록과 무관하다(정상).

추가 6종: 트론(TRX)·체인링크(LINK)·폴카닷(DOT)·폴리곤(MATIC)·아발란체(AVAX)·코스모스(ATOM). 각 실제 심볼·한글명·현실적 시드가·브랜드색(데이터성 색상, 하드코딩 hex 예외). `generateStaticParams`가 로스터 전체를 사전 생성하므로 거래 화면 딥링크도 12종으로 늘어난다.

## 6. 접근성

- 대비: 방향 소형 텍스트 `-text`(600), 정보 라벨 `--text-secondary` 이상, sunken 위는 `--text-default`.
- 탭 타깃: 행·버튼 히트영역 44px 이상.
- reduced-motion: TickCell·틱 플래시는 기존 킬스위치를 그대로 상속.
- 라벨: 행 버튼 `aria-label`, 등락률 `aria-label`(`ariaChangeLabel`), 테이블 role, 탭 `aria-selected`. Sparkline은 장식이라 `aria-hidden`이고 수치는 카드 텍스트로 대체 제공.
