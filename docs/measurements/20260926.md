원자료와 주행 전에 고정한 판정 규칙은 [pml-app3-read-20260926-1220](../../harness/evidence/pml-app3-read-20260926-1220/README.md)에 있다. 사용자가 확정한 앱 계층 모델(app-1·app-2는 늘 켜진 매칭 리더이고 조회도 처리, app-3은 조회 전용이며 AWS에서 ASG가 0~1대로 늘리고 줄임)을 S7의 최종 조합(P3와 파티션·중계 LB 파일 `nginx.partition-relay.conf`)에서 확인했다. 스택은 S7 관문과 같은 폐기용 스택(compose 프로젝트 `exchange-pml`, 이미지 `exchange-chaos-app:pml` `sha256:267c799f…`, 다시 굽지 않음)이다. 기본 compose의 `chaos-api-3`은 9/23 측정 조건을 지키려고 `dev,chaos-monkey` 구성으로 남아 있어, 새 오버레이 `harness/docker-compose.read-node.yml`로 AWS 조회 노드와 같은 `prod,read` 프로파일, 조회 전용 DB 로그인(배포 스크립트 `deploy/provision-runtime-roles.sql`로 폐기용 DB에 만듦), 풀 8로 띄웠다.
