# 정밀감사 2차

## 개요

- 방법: 소스 201파일 전담(파일 단위) 심층 리뷰. 각 파일의 계약·불변식·경계 조건을 정본 문서와 교차 대조하고, high·medium 후보는 인과 사슬을 파일 직접 인용으로 재구성하는 적대적 재검증을 거쳐 확정한다.
- 제약: 읽기 전용. 빌드·테스트·스타일 게이트 미실행(동시 빌드 금지). 근거는 file:line 정적 추적으로 완결.
- 1차(개선_백로그.md) 대비: 동일 지점·동일 원인은 "1차 중복"으로 표기하고, 심각도가 재판정으로 바뀐 경우 방향을 병기한다. 2차 신규 발견을 전면에 세운다.
- 심각도 판정: rubric 3밴드. critical(자산·복구·보안 파손), high(계약 위반·구현 차단·오해석 유발), medium(실질 내부 불일치), low(표기·정리·하드닝). 재검증에서 다수 high 후보가 영향 범위 확인 뒤 medium으로 하향, 1차 medium 1건(BEST 매수 NPE)은 오해석 유발이 결정적이라 high로 상향.
