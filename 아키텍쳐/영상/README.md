# 실제 시연 영상

실제 실행을 녹화한 파일을 둘 곳이다. 현재 녹화 파일은 없다. 촬영할 장면과 판정 기준은 [아키텍쳐 안내](../README.md)를 따른다.

촬영 뒤 `날짜_환경_실험명` 폴더 안에 `원본.mp4`와 `발표용.mp4`를 구분해 둔다. 원본은 장애 주입부터 회복까지의 시간을 확인할 수 있도록 보관한다. 발표용 영상은 원본에서 편집하고, 생략 구간을 실제 복구 시간처럼 보이게 하지 않는다.

같은 폴더에 짧은 촬영 정보 파일을 남긴다. 날짜·시간대, LOCAL 또는 AWS, 커밋·이미지 digest, 노드 구성과 리스 제공자, 부하, 장애 종류, 판정과 원자료 경로를 적으면 된다. 별도 발표 대본은 만들지 않는다. 용량이 큰 영상은 커밋하기 전에 저장 위치와 배포 방식을 정한다.
