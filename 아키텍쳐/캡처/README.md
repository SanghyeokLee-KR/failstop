# 실제 실행 캡처

새로 촬영한 AWS 배치·거래·장애·부하·검사 결과를 둘 곳이다. 현재 새 캡처는 없다. 교수님께 이미 보여 드린 화면은 [기존 보고본](../교수님_보고본/05_화면/)에 보존했다.

영상과 같은 `날짜_환경_실험명` 폴더를 사용하고, 파일명에는 `정상`, `장애주입`, `거래재개`, `검사결과`처럼 장면을 적는다. 같은 폴더의 촬영 정보에 원본 영상 시각, 실험 식별자와 검증 원자료 경로를 연결한다.

지표는 축·단위·시간 범위가 읽혀야 한다. 장애 전후 비교는 같은 기준을 사용한다. 화면 소개용 이미지와 실험 결과 이미지를 구분하고, 비밀 값이 노출된 이미지는 발표에 사용하지 않는다. 필요한 장면은 [아키텍쳐 안내](../README.md)에 정리했다.
