# 접수 저널 append 단축 전후 대조 (2026-09-11)

조치 둘을 함께 넣고 쟀다. 정본 5.7.12 가 판정이다.

- 조치 1. append 의 앞 네 문장을 함수 하나로 묶는다(`V39__append_prologue.sql`).
  리더 검증과 어드바이저리 락과 멱등 조회와 전역 채번이다. 삽입은 체크섬 계약 때문에 뺀다.
- 조치 2. append 전용 커넥션 풀을 둔다(`exchange-append`, 크기 2). 접수 락이 이미
  직렬화하므로 동시에 둘 이상 쓸 일이 없다.

## 조건

전후가 같다. 12마켓, 데이터베이스 4 vCPU / 4g, 커넥션 풀 32, 칸마다 볼륨 파기,
`calibrate.js` 130초, 부하 시드는 고친 값이다.
