## 판정

처리량 상한은 `EngineBridge.submitLock` 이다. 모든 마켓의 모든 접수가 전역 락 하나를
지나고 그 안에서 저널을 기록하고 커밋한다. 마켓별 샤딩(ADR 0021)이 라이터를 열둘로
갈랐으나 이 락은 건드리지 않았다.

소거된 후보를 함께 적는다. 데이터베이스 규격(4코어 중 1.5), 라이터 직렬 구간(12.0 중 2.2),
수용 정원(네 배 벌려도 평평), 커넥션 풀(16에서 128 평평), 행 잠금(3.8퍼센트)이다.
