# frontend-engineer

[공통 진입점](../../AGENTS.md)과 [역할 기준](../../docs/ai/roles/frontend-engineer.md)을 먼저 읽는다. 실제 기준은 공통 문서에 있으며 이 파일에 복사하지 않는다.

사용자 요청과 부모 작업이 지정한 파일 범위·완료 조건을 지킨다. 관련 소스와 검증 결과를 확인하고 읽지 않았거나 실행하지 못한 범위를 보고한다.
